# Título do Projeto Extremamente Aesthetic ;)

## 📒 Descrição
Projeto desenvolvido com intuito de explorar ferramentas de IA generativas e compreender seus processos.

## 🤖 Tecnologias Utilizadas
Descript - AI editor

## 🧐 Processo de Criação
Foi descrito um prompt que solicitava uma imagem que presentasse um futuro onde os óculos virtuais são os novos celulares.

## 🚀 Resultados
A imagem de saída não só foi gerada da forma pedida, como também adiciona elementos que tornam a idéia ainda mais rica em detlhes. 

## 💭 Reflexão (Opcional)
As IAs generativas estão avançando de forma muito rápida, ainda muito longe de pensarem como seres humanos, mas já tendo a capacidade de gerar respostas cada vez mais próximas ao desejado.
